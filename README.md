# 番茄钟 (Pomodoro Timer)

基于 Electron 构建的桌面番茄钟应用。

## 功能特性

- **三种模式**：专注（25分钟）、短休息（5分钟）、长休息（15分钟）
- **环形进度条**：SVG 圆环实时显示倒计时进度
- **会话追踪**：每完成 4 个番茄自动进入长休息
- **通知提醒**：计时结束时播放提示音并弹出系统通知
- **托盘支持**：关闭窗口后驻留托盘，点击可恢复
- **自定义设置**：可调整各阶段时长和长休息间隔
- **键盘快捷键**：空格开始/暂停，R 重置
- **配置持久化**：设置保存在 localStorage，关闭后保留

## 核心逻辑

### 模块一：配置管理

定义番茄钟的默认配置（单位：秒），从浏览器的 `localStorage` 中加载用户之前保存的配置，这样用户关闭应用后再次打开时设置会被保留。

```js
let config = {
  work: 25 * 60,           // 专注时长：25分钟
  shortBreak: 5 * 60,      // 短休息时长：5分钟
  longBreak: 15 * 60,      // 长休息时长：15分钟
  sessionsBeforeLong: 4    // 每完成4个番茄后进行长休息
};
```

### 模块二：状态变量

跟踪 5 个核心状态：

| 变量 | 说明 |
|------|------|
| `currentMode` | 当前模式：`work` / `shortBreak` / `longBreak` |
| `totalSeconds` | 当前模式的总时长（秒） |
| `remainingSeconds` | 倒计时剩余时间（秒） |
| `isRunning` | 计时器是否正在运行 |
| `completedSessions` | 累计已完成的番茄数量 |

### 模块三：UI 渲染

`render()` 是核心函数，每次状态变化后调用，更新：

- **倒计时文字** — 将秒数格式化为 `MM:SS`
- **SVG 进度环** — 通过 `strokeDashoffset` 控制圆弧显示比例
- **按钮文字** — 运行时显示"暂停"，未运行时显示"开始"
- **会话进度点** — 用取模运算处理多个长周期循环
- **窗口标题和托盘** — 任务栏和托盘上直接显示剩余时间

### 模块四：计时器控制

- `startTimer()` — 启动/暂停切换，`setInterval` 每秒减少 1 秒
- `onTimerComplete()` — 时间到零时触发，播放提示音并弹出通知
  - 专注完成 → 番茄数 +1，进入短休息（或每 4 个番茄进入长休息）
  - 休息完成 → 切换回专注模式

### 模块五：模式切换

`switchMode()` 同时处理 3 件事：

1. 改变 `body` 的 `data-mode` 属性，CSS 根据这个属性切换主题色（专注=红色，短休息=青色，长休息=蓝色）
2. 重置计时器到对应模式的初始时长
3. 更新顶部标签页的高亮状态

### 模块六：事件处理

- **按钮** — 开始/暂停、重置、跳过
- **标签页** — 运行时禁止切换，防止状态混乱
- **键盘** — 空格键开始/暂停，R 键重置（输入框内不响应）
- **设置弹窗** — 打开时填充当前配置，保存后持久化并重置计时器

## 工作流程

```
开始专注 (25min) → 计时结束 → 完成番茄 +1
    ↓
每 4 个番茄  ──→  长休息 (15min)
    ↓                    ↓
短休息 (5min)         回到专注
    ↓
回到专注 ──────────────┘
```
